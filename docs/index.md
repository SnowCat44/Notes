## 사용법 요약

- **검색**: 상단 검색창에서 한글·영어 모두 검색됩니다.
- **새 항목 추가**: 해당 구역 폴더에 `.md` 파일을 만들고, `mkdocs.yml`의 `nav`에 한 줄 추가합니다.

- **수식**: 인라인은 `$...$`, 블록은 `$$...$$` 로 작성합니다. (예: $E=mc^2$)
- **코드/알고리즘**: 삼중 백틱 코드 블록에 언어를 지정하면 문법이 강조됩니다.
